## Problem and bounded solution

[Earlier sanitized evidence](evidence/F2_IPHONE_ATTEMPT_2026-10-27.json) is preserved. All 22 existing test/helper Swift files are direct references, not copies. On iOS, three original macOS-only declarations remain compile-time exclusions (two child-process liveness tests and one native untrusted-TLS test); expected/observed iOS runtime coverage is 215 tests/26 suites. No iOS test is deliberately skipped or filtered. [Inventory](TEST_INVENTORY.md) and [contract ledger](TEST_EVIDENCE.md) retain the actual assertions and evidence-type limits. iOS scripted branches do not become native server/TLS evidence by running on hardware.

The app displays a static label and contains no networking/client creation. It requests no new capability, entitlement, ATS exception or local-network permission. Bundle IDs are scoped to this test host; account, certificate, profile and device identifiers are never checked in. A private NETWORKKIT_DEVICE_PROFILE override is referenced only by the host/test targets; it avoids assigning provisioning profiles to Swift-package resource/library targets. No actual profile value is present in the project. Existing Xcode-managed profiles require a local Automatic override, with explicit profile specifier empty and no provisioning-update/device-registration flags. The default remains Manual for review safety; verify the embedded profile against the existing local profile before installation.

## Verification controls and quality assessment

Source integrity now validates exact shared-source membership, local package/product, app-host target/dependency/TEST_HOST, approved deployment/language settings, unfiltered scheme and absence of committed private signing/entitlement settings. Five helper checks cover the valid project and negative mutations for missing source, tool-host substitution, remote package substitution and a committed profile identifier; with the four existing helper tests, nine checks are required. ios-core additionally compiles the generic physical app/test route with signing disabled, preserving the original five-runtime package matrix and existing runner/job concurrency limits. The checked-in Xcode project is the reviewable build source. The next run built but failed before launch with CoreSimulator Invalid connectionUUID; the selected simulator was Shutdown. An explicit bounded simctl bootstatus -b succeeded, followed by one successful test run. Preserve these distinct preparation failures; no NetworkKit or universal simulator root cause is inferred.
